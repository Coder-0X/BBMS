What do these targets do?
  • Days of Supply Target — when available stock falls below this many days of estimated demand, a low_inventory alert fires.
  • Max Wastage % — percentage threshold above which a high_wastage alert fires (not yet automatic — check the reports page).
  • Near-Expiry Alert (h) — units expiring within this window trigger a near_expiry alert.
  • Max C:T Ratio — if the crossmatch-to-transfusion ratio for this component exceeds this over the last 30 days, a ct_ratio_high alert fires.
